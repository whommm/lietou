> 记录时间：2026-04-13
> 适用场景：项目从原路径（如 `E:\Lietou`）复制到新电脑/新路径后，双击 `启动程序.bat` 无法启动；以及使用 `kimi-for-coding` / `deepseek-reasoner` 等思考模型时，公司调研等功能报错或只输出思考过程。

## 一、启动程序.bat

### 问题现象
双击 `启动程序.bat` 后提示：
- `No Python at 'E:\Lietou\python.exe'`
- `依赖安装失败`
- 或者直接一闪而过没反应

### 根因
1. 虚拟环境 `venv` 内部硬编码了旧路径 `E:\Lietou`，移动项目后找不到解释器。
2. `pip.exe` 内部也写死了旧路径，直接使用 `venv\Scripts\pip.exe` 会失败。
3. 批处理文件之前被保存成了 Unix 换行符（`LF`），Windows `cmd.exe` 解析时会把整行拆碎。

### 修改内容
把 `启动程序.bat` 中安装依赖的那一行：

```bat
venvfmpeg -i input.mp4 output.mp4 Scriptsfmpeg -i input.mp4 output.mp4 pip.exe install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

改为：

```bat
venvfmpeg -i input.mp4 output.mp4 Scriptsfmpeg -i input.mp4 output.mp4 python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

同时确保整个 `.bat` 文件使用 **CRLF 换行符**（Windows 标准）。如果用 VS Code 编辑，看右下角要确保显示的是 `CRLF`，不要是 `LF`。

### 完整参考内容
```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"

echo ====================================
echo 智能岗位分析与寻访助手
====================================

    echo [错误] 未找到虚拟环境 venv
    echo 请先创建虚拟环境: python -m venv venv
    pause
    exit /b 1
)

echo [检查] 检查依赖包...
venv\Scripts\python.exe -c "import customtkinter, openpyxl" 2>nul
if errorlevel 1 (
    echo [安装] 正在安装依赖包...
    venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    if errorlevel 1 (
        echo [错误] 依赖安装失败
        pause
        exit /b 1
    )
)

echo [启动] 启动程序...
venv\Scripts\python.exe main.py

if errorlevel 1 (
    echo.
    echo [错误] 程序运行出错
    pause
)
```

## 二、src/core/llm_client.py（核心修改）

### 问题现象
使用 `kimi-for-coding`（或 `deepseek-reasoner`）等思考模型时：
1. 公司调研/岗位分析报错：`API 请求失败: Request failed with status code 400`
2. 或者只输出满屏思考过程，真正的 HTML/答案一点没有
3. 或者提示 `'NoneType' object is not subscriptable`

### 根因
1. **思考模型不支持 `temperature` 参数**：代码里固定写了 `temperature=0.7`，思考模型会报 400。
2. **`max_tokens=4096` 太小**：思考过程会吃掉大量 token，导致最终答案还没生成就被截断。
3. **非流式返回缺失最终答案**：你用的 `localhost:3000` 代理在非流式 (`stream=False`) 时，只把思考过程塞到 `<think>` 标签里，`content` 是空的。
4. **思考过程泄露到前端/Excel**：返回内容里包含 `<think>...</think>`，用户直接看得到。

### 修改内容
直接替换 `src/core/llm_client.py` 的**整个文件**为以下内容：

```python
"""LLM API 客户端模块"""

import re
import time
from openai import (
    OpenAI,
    APIError,
    AuthenticationError,
    APITimeoutError,
    APIConnectionError,
)
from typing import Optional
from .prompt import SYSTEM_PROMPT, MATCH_CRITERIA_PROMPT_APPENDIX


class LLMClientError(Exception):
    pass


class AuthError(LLMClientError):
    pass


class NetworkError(LLMClientError):
    pass


class TimeoutError(LLMClientError):
    pass


class LLMClient:
    MAX_RETRIES = 2
    RETRY_DELAY_BASE = 1.0

    def __init__(
        self,
        api_base_url: str,
        api_key: str,
        model_name: str = "deepseek-chat",
        timeout: int = 120,
    ):
        self.api_base_url = api_base_url.rstrip("/")
        self.api_key = api_key
        self.model_name = model_name
        self.timeout = timeout
        self._client: Optional[OpenAI] = None

    def _get_client(self) -> OpenAI:
        if self._client is None:
            self._client = OpenAI(
                api_key=self.api_key, base_url=self.api_base_url, timeout=self.timeout
            )
        return self._client

    def _execute_with_retry(self, func, *args, **kwargs):
        last_error = None
        for attempt in range(self.MAX_RETRIES + 1):
            try:
                return func(*args, **kwargs)
            except AuthError:
                raise
            except (NetworkError, TimeoutError) as e:
                last_error = e
                if attempt < self.MAX_RETRIES:
                    delay = self.RETRY_DELAY_BASE * (2**attempt)
                    time.sleep(delay)
            except (APIError, Exception) as e:
                translated = self._translate_exception(e)
                if isinstance(translated, AuthError):
                    raise translated
                last_error = translated
                if attempt < self.MAX_RETRIES:
                    delay = self.RETRY_DELAY_BASE * (2**attempt)
                    time.sleep(delay)
        raise last_error or LLMClientError("请求失败")

    @property
    def _is_reasoning_model(self) -> bool:
        """检测当前是否为思考模型"""
        name = self.model_name.lower()
        return any(k in name for k in ("reasoner", "coding", "thinking", "k1.5", "k1"))

    def _get_max_tokens(self) -> int:
        """根据模型类型返回合适的 max_tokens"""
        return 8192 if self._is_reasoning_model else 4096

    @staticmethod
    def _clean_content(content: str) -> str:
        """清理模型返回内容，移除思考过程等"""
        if not content:
            return ""
        # 移除 <think>...</think> 标签及其内容
        content = re.sub(r"<think>.*?</think>", "", content, flags=re.DOTALL)
        # 移除多余的空行
        content = re.sub(r"\n{3,}", "\n\n", content)
        return content.strip()

    @staticmethod
    def _translate_exception(e: Exception) -> LLMClientError:
        if isinstance(e, AuthenticationError):
            return AuthError("API 密钥无效或账户余额不足，请检查后重试。")
        if isinstance(e, APITimeoutError):
            return TimeoutError("请求超时，请稍后重试。")
        if isinstance(e, APIConnectionError):
            return NetworkError("无法连接到大模型服务器，请检查网络或 API 地址。")
        if isinstance(e, APIError):
            if "insufficient_quota" in str(e).lower():
                return AuthError("账户余额不足，请充值后重试。")
            return LLMClientError("API 请求失败: {}".format(str(e)))
        return LLMClientError("未知错误: {}".format(str(e)))

    def _call_api(self, client, kwargs):
        """统一调用 API，思考模型使用流式获取完整内容。"""
        if self._is_reasoning_model:
            kwargs["stream"] = True
            response = client.chat.completions.create(**kwargs)
            chunks = []
            for chunk in response:
                if chunk.choices and chunk.choices[0].delta and chunk.choices[0].delta.content:
                    chunks.append(chunk.choices[0].delta.content)
            return self._clean_content("".join(chunks))
        else:
            response = client.chat.completions.create(**kwargs)
            if not response.choices:
                raise LLMClientError("API 返回为空，未生成任何内容。")
            message = response.choices[0].message
            if message is None:
                raise LLMClientError("API 返回消息为空。")
            return self._clean_content(message.content or "")

    def _do_analyze_jd(self, jd_text: str, company_context: str = "") -> str:
        client = self._get_client()

        user_message = jd_text
        if company_context:
            user_message = f"\u3010\u516c\u53f8\u80cc\u666f\u4fe1\u606f\u3011\n{company_context}\n\n\u3010\u5c97\u4f4d\u63cf\u8ff0\u3011\n{jd_text}"

        kwargs = {
            "model": self.model_name,
            "messages": [
                {
                    "role": "system",
                    "content": SYSTEM_PROMPT + MATCH_CRITERIA_PROMPT_APPENDIX,
                },
                {"role": "user", "content": user_message},
            ],
            "max_tokens": self._get_max_tokens(),
        }
        if not self._is_reasoning_model:
            kwargs["temperature"] = 0.7
        return self._call_api(client, kwargs)

    def analyze_jd(self, jd_text: str, company_context: str = "") -> str:
        return self._execute_with_retry(self._do_analyze_jd, jd_text, company_context)

    def _do_chat(self, user_message: str, system_message: str = "") -> str:
        client = self._get_client()
        messages = []
        if system_message:
            messages.append({"role": "system", "content": system_message})
        messages.append({"role": "user", "content": user_message})

        kwargs = {
            "model": self.model_name,
            "messages": messages,
            "max_tokens": self._get_max_tokens(),
        }
        if not self._is_reasoning_model:
            kwargs["temperature"] = 0.7
        return self._call_api(client, kwargs)

    def chat(self, user_message: str, system_message: str = "") -> str:
        return self._execute_with_retry(self._do_chat, user_message, system_message)
```

### 关键改动说明
1. **`_is_reasoning_model`**：模型名包含 `reasoner`、`coding`、`thinking`、`k1.5`、`k1` 时自动识别为思考模型。
2. **`_get_max_tokens`**：思考模型用 `8192`（给思考+输出留足空间），普通模型保持 `4096`。
3. **`_call_api`**：
   - 思考模型走 `stream=True` 流式调用，逐块拼接完整内容（解决非流式返回缺失最终答案的问题）。
   - 普通模型维持原逻辑不变。
4. **`_clean_content`**：用正则过滤 `<think>...</think>` 标签，确保前端 UI 和 Excel 里不会暴露思考过程。
5. **`temperature` 兼容**：思考模型自动跳过该参数，避免报 400。

## 三、venv/pyvenv.cfg（可选）

如果你的项目也是从别的盘符/路径复制过来的，需要检查一下 `venv/pyvenv.cfg`：

```ini
home = D:\Lietou
include-system-site-packages = false
version = 3.8.10
```

确保 `home` 指向的是你当前项目根目录下的 `python.exe` 所在路径。如果虚拟环境是重新创建的，则不需要改这个文件。

## 四、回家后的操作步骤

1. 打开家里的源码项目。
2. **替换** `src/core/llm_client.py` 为上面的完整代码。
3. **修改** `启动程序.bat` 中的 `pip.exe` 为 `python.exe -m pip`，并确保文件换行符是 `CRLF`。
4. （可选）如果项目是从别的路径复制过来的，检查并修正 `venv/pyvenv.cfg` 里的 `home` 路径。
5. **删除所有 `__pycache__` 缓存文件夹**（避免 Python 加载旧编译缓存）。
6. 重新双击 `启动程序.bat` 启动程序，即可正常使用思考模型。
